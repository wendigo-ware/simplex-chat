This is a super cool fork of the SimpleX client. It is intended to prioritize censorship resistance, privacy, security and user autonomy, along with a few quality of life improvements.

### Planned changes

**More censorship resistance:**
- Evade media blocking and other censorship techniques

**More user autonomy & security:**
- No disabling client functionality at somebody else's request
- Group owners decide how their groups will be moderated
- More secure chat preferences (enforced by the receiver)
- Chat preference spoofing
- Attempt any action, despite others' chat preferences

**More privacy:**
- No back doors for leaking unencrypted data, whether it's been "reported" or not
- Better defaults
- Better profile isolation
- Tor integration

**Quality of life improvements:**
- Random name colors & avatars for incognito profiles
